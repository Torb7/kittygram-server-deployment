# Kittygram — развёртывание на удалённом сервере

Практический проект по развёртыванию веб-приложения Kittygram на удалённом сервере Ubuntu.

Исходный код приложения предоставлен в рамках образовательного задания. Моя задача заключалась в настройке серверной инфраструктуры и развёртывании приложения.

## Мой вклад

- Подключился к удалённому серверу Ubuntu по SSH.
- Настроил межсетевой экран UFW.
- Настроил Gunicorn для запуска Django-приложения.
- Создал systemd-сервис для управления процессом Gunicorn.
- Настроил Nginx в качестве веб-сервера и обратного прокси (reverse proxy).
- Настроил обслуживание frontend, статических и медиафайлов.
- Собрал frontend и подготовил его к размещению на сервере.
- Настроил HTTPS с использованием SSL-сертификатов.
- Настроил права доступа к необходимым директориям.

## Технологии

- Linux (Ubuntu)
- SSH
- Nginx
- Gunicorn
- systemd
- UFW
- SSL/TLS
- npm

## Структура проекта

```text
kittygram/
├── backend/                 # Исходный код Django-приложения
├── frontend/                # Исходный код frontend
├── infra/
│   ├── default              # Конфигурация Nginx
│   └── gunicorn_kittygram.service
└── README.md
```

## Инфраструктурные конфигурации

В директории `infra/` находятся конфигурационные файлы, подготовленные мной в ходе развёртывания:

- `default` — конфигурация Nginx для обслуживания frontend, статических и медиафайлов, а также проксирования запросов к backend.
- `gunicorn_kittygram.service` — конфигурация systemd-сервиса для запуска и управления Gunicorn.

## Этапы развёртывания

Развёртывание приложения выполнялось вручную на удалённом сервере Ubuntu.

1. Подключение к серверу по SSH.
2. Подготовка серверного окружения и настройка UFW.
3. Размещение приложения на сервере.
4. Настройка Gunicorn и создание systemd-сервиса.
5. Настройка Nginx для обслуживания frontend и проксирования запросов к backend.
6. Настройка директорий для статических и медиафайлов.
7. Сборка frontend и размещение собранных файлов на сервере.
8. Настройка HTTPS с использованием SSL-сертификатов.

## Результат

В результате было развёрнуто готовое Django-приложение Kittygram на удалённом сервере с настроенными Nginx, Gunicorn, systemd и HTTPS.

Проект демонстрирует практические навыки работы с Linux-сервером, настройки веб-сервера и WSGI-сервера, управления системными службами и ручного развёртывания Django-приложений.
